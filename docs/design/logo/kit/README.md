# Benjaire logo kit (transparent "B" mark)

Source: docs/design/logo/v3/svg (the same mark as the app icon, benjaire-app-icon-light.png).
Every file has a transparent background.

| Folder | Use on | Look |
|---|---|---|
| on-light/ (graphite) | white, cream, light photos | primary, metallic gradient |
| on-dark/ (pearl) | black, charcoal, dark photos | primary reverse, silver gradient |
| on-light-flat/ (charcoal) | one-color jobs: embroidery, stamps, fax, tiny sizes | flat dark |
| on-dark-flat/ (white) | one-color on dark: engraving, vinyl, video overlays | flat white |

- SVG = master, scales to any size (print, signage, web).
- PNG 512 / 1024 / 2048 = square transparent canvas with clear space built in (social avatars, decks, docs).
- Clear space: keep empty space around the mark at least the width of the B's stem.
- Minimum size: about 16 px tall on screen, 0.25 in in print. Below that use the flat versions.
- Don't stretch, recolor, add shadows, or put the gradient version on busy photos.
